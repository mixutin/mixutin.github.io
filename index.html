0x10about

About

I'm mixutin. I'm a cybersecurity specialist, and I love playing capture-the-flag (CTF) competitions. My favourite part of any problem is taking a program apart to find out how it really works.

Lately that has meant game preservation. When a game's official servers shut down, the game often stops working for everyone, even for people who still have it installed. I study the game client, work out what it expects from its servers, and write or fix server code so it can be played again.

I want to preserve more than games: overlooked media that has no posts or copies on the Internet Archive matters to me too. I am also working toward cybersecurity certifications.

Around that I build backends, systems-level tools and game-development tools, including MCP servers that let AI coding assistants work inside creative apps.

featured project

Dauntless Revived

A private-server revival of Dauntless, Phoenix Labs' free-to-play co-op monster-hunting game. Its official servers shut down on 30 May 2025. This project runs the genuine Dauntless 1.4.4 client (October 2020, Unreal Engine 4) against a self-hosted backend.

A modified fork of Undaunted by gwog (Gregory Morford) and contributors, licensed AGPL-3.0. Undaunted did the groundwork. This fork adds hardening, a friend kit and documentation, and it is working on saving progression (M2).

Project page → Docs GitHub

Not a public server: it is run for a few friends, and anyone can self-host it from the repository. No game files are distributed by this site or the repository.

works today · solo, on the host PC

  • Log in with a personal account key, no Epic account
  • Tutorial, Ramsgate (the hub city) and the Training Dojo
  • Real hunts (a Lesser Boreus, a pursuit) and crafting
  • Inventory, gear and quests saved across restarts
  • Hourly backups

not yet

  • Friends over the internet (planned via Tailscale)
  • Parties and the friends list
  • Real progression and the Hunt Pass M2

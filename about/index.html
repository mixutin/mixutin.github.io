BEHIND / 0x11a

Taking things apart.
Making things possible.

My favourite part of a problem is finding out how it really works. That might mean studying a cipher, reading machine code or tracing what a game client expects from a server.

Game and media preservation matter to me. Software should not disappear just because a service goes offline. I also build native desktop tools, backends and systems-level experiments.

CTF competitions keep me learning. Open-source projects give those ideas somewhere practical to go.
